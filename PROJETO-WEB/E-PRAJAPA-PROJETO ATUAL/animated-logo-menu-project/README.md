# Animated Logo and Menu Project

This project implements a simple webpage featuring an animated logo and a sliding menu. The logo appears to fall into place, while the menu slides in from the right, creating an engaging user experience.

## Project Structure

```
animated-logo-menu-project
├── src
│   ├── css
│   │   ├── reset.css        # CSS reset styles for consistent rendering
│   │   └── style.css        # Main styles and animations
│   ├── js
│   │   └── animation.js      # JavaScript for handling animations
│   ├── imagens
│   │   └── logo.png         # Logo image used in the project
│   └── index.html           # Main HTML file
└── README.md                # Documentation for the project
```

## Setup Instructions

1. **Clone the Repository**: 
   ```bash
   git clone <repository-url>
   cd animated-logo-menu-project
   ```

2. **Open the Project**: 
   Open the `index.html` file in your preferred web browser to view the animations.

3. **Modify Styles and Animations**: 
   You can customize the animations and styles by editing the `style.css` and `animation.js` files.

## Animations Overview

- **Falling Logo**: The logo is animated to appear as if it is falling into place when the page loads. This is achieved using CSS keyframes defined in `style.css`.

- **Sliding Menu**: The menu slides in from the right side of the screen and centers itself, enhancing the visual appeal of the navigation.
